# Пульт сбора матчей

Сайт на своей машине для работы с базой краулера (`project/data/base.sqlite`):
запуск и остановка сбора, сборка пака, и сводка — сколько собрано и сколько
ещё не хватает для надёжных советов.

## Запуск

Двойной щелчок по **`start-crawler.cmd`** в корне репозитория. Он при первом
запуске ставит зависимости интерфейса, при каждом — пересобирает его (пара
секунд), поднимает сервер и открывает `http://127.0.0.1:8790` в браузере.
Нужны Python 3.11+ и Node.js 20+ (без Node запустится ранее собранный
интерфейс, если он есть).

Окно `start-crawler.cmd` — это сервер пульта: закрыли окно — пульт и идущий
сбор остановились.

## Когда сбор останавливается

Сбор идёт без срока, пока не случится одно из:

- **«Остановить»** — мягко: `crawl.py` докачивает текущий матч и выходит
  (Ctrl+Break). Второе нажатие снимает процесс сразу.
- **Закрыты все вкладки пульта.** Страница каждые 2 секунды отмечается
  у сервера, а при закрытии сообщает об уходе. Нет живых вкладок — сервер
  мягко останавливает сбор (перезагрузка страницы — не уход: есть 15 секунд
  на возвращение). Упал браузер или вкладку убили без прощания — сервер
  заметит тишину через 2,5 минуты: свёрнутый Chrome будит таймеры страниц
  раз в минуту, и меньший порог ложно останавливал бы сбор.
- **Закрыт или упал сервер.** Процессы задач сидят в задании Windows
  (Job Object) с `KILL_ON_JOB_CLOSE`: система снимает их вместе с сервером,
  даже если его убили в диспетчере задач.

Базе всё это не вредит: каждый матч пишется отдельной транзакцией.

## Вкладки

| Вкладка | Что там |
|---|---|
| Сбор | параметры и запуск `crawl.py`, идущий сбор, коротко о базе |
| База | матчи, наблюдения, темп, очередь игроков, патчи, ранги посева, паки |
| Покрытие | доля игр в сочетаниях с достаточной выборкой и сколько матчей (часов) нужно до 80–90% |
| Чего не хватает | основные роли чемпионов с малой выборкой и сколько матчей нужно каждой |
| Пак и обслуживание | собрать пак, докачать timeline, посев игроков, оставить один патч |
| Журнал | вывод скриптов; красная цифра на вкладке — новые ошибки |

У каждого поля и кнопки — пояснение прямо на странице.

## Устройство

```
crawler_dashboard/
  server.py     сервер: stdlib Python, задачи, сводка по базе, раздача web/dist
  web/          интерфейс: Vue 3 + Vite + TypeScript + Tailwind 4
    src/App.vue          вкладки, опрос сервера, действия
    src/components/      по компоненту на вкладку
    src/api.ts           типы ответов, пульс вкладки, запросы
```

Сервер берёт функции `scripts/build_pack.py` (противник на линии, ранговые
корзины, выбор патча), поэтому покрытие считается теми же сочетаниями,
что строит пак.

Правка интерфейса с горячей перезагрузкой:

```powershell
python crawler_dashboard/server.py --no-browser     # сервер на :8790
cd crawler_dashboard/web; npm run dev               # страница на :5175, /api проксируется
```

## Безопасность

Сервер слушает только `127.0.0.1` и выполняет только команды из списка
в `server.py` — параметры из браузера проверяются по формату, произвольных
строк в командной строке нет. Действия (POST) требуют заголовка
`X-Dashboard-Action` и своего `Host`/`Origin`: чужой сайт в том же браузере
сбор не запустит. Ключ Riot страница не видит — только «найден / не найден».
