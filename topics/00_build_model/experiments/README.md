# Эксперименты темы 0: сломать сборку четырьмя способами

Эти файлы **не входят в сборку курса**. Их надо компилировать руками — в этом весь смысл.
Ты должен увидеть каждую ошибку своими глазами и научиться читать её текст, потому что
через неделю ты встретишь её в своей задаче, и тогда времени разбираться уже не будет.

## Как компилировать

**Windows.** Открой «Developer PowerShell for VS 2026» (меню «Пуск» → набери «Developer PowerShell»).
Обычный PowerShell не подойдёт: в нём нет `cl.exe`. Дальше:

```powershell
cd topics\00_build_model\experiments\e01_undefined_reference
cl /nologo /std:c++17 /EHsc main.cpp
```

**Linux/macOS:**

```bash
cd topics/00_build_model/experiments/e01_undefined_reference
g++ -std=c++17 main.cpp -o main
```

Где нужно собрать несколько файлов, точная команда лежит в комментарии в начале `main.cpp`.

## Что делать с каждым экспериментом

1. Прочитай комментарий в начале файла — там написано, что сломано.
2. Скомпилируй. Получи ошибку.
3. **Запиши в `PROGRESS.md` (раздел «Слабые места» → «Тема 0»), какая это ошибка: компилятора или линкера.** Это главный вопрос темы.
4. Почини минимальным изменением. Собери ещё раз.

## Четыре эксперимента

| Папка | Что сломано | Кто ругается | Код ошибки MSVC | Код ошибки GCC/Clang |
|---|---|---|---|---|
| `e01_undefined_reference` | функция объявлена, но нигде не определена | линкер | LNK2019 | `undefined reference to` |
| `e02_no_include_guard` | заголовок включён дважды, защиты нет | компилятор | C2011 | `redefinition of 'struct'` |
| `e03_odr_violation` | тело функции в заголовке, заголовок включён в две единицы трансляции | линкер | LNK2005 | `multiple definition of` |
| `e04_signature_mismatch` | объявление и определение разошлись в типе параметра | линкер | LNK2019 | `undefined reference to` |

Ключевое наблюдение, ради которого всё это: **e01 и e04 дают одну и ту же ошибку линкера,
хотя причины разные**. Линкер не знает, забыл ты написать функцию или опечатался в
сигнатуре — он просто не нашёл символ. Читать надо не первую строку, а имя символа в ней:
в e04 в нём видно `double`, которого ты не ожидал.

И второе: **e02 — это ошибка компилятора, e03 — линкера, хотя обе про «уже определено».**
Компилятор видит одну единицу трансляции целиком, линкер — все объектные файлы сразу.
Кто ругается, тот и подсказывает, где искать.
