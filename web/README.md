# web — интерфейс оверлея

Vue 3 + Vite + TypeScript. Живёт в окне WebView2 внутри `sintence.exe`,
данные берёт у него же по HTTP.

## Как запускать

**Обычный режим.** Собрать фронт один раз, дальше работать с C++:

```
cd web
npm install        # только в первый раз
npm run build      # кладёт сборку в web/dist
cd ..
cmake --build build --config Debug --target sintence
build\src\Debug\sintence.exe
```

**Режим разработки интерфейса.** Горячая перезагрузка, DevTools, обычный браузер:

```
build\src\Debug\sintence.exe   # в одном окне: он отдаёт /api/live
cd web && npm run dev          # в другом: http://localhost:5173
```

Vite проксирует `/api` на `127.0.0.1:8777`, поэтому страница в браузере
видит настоящие данные идущего матча. Пересобирать C++ при правке CSS не нужно.

## Что откуда берётся

| Файл | Зачем |
|---|---|
| `src/types.ts` | форма JSON от `sintence.exe`, зеркало `core/live_game.h` |
| `src/useLiveGame.ts` | опрос `/api/live` раз в секунду, четыре состояния ленты |
| `src/App.vue` | панель целиком: шапка, две команды, пустые состояния |
| `src/components/PlayerRow.vue` | строка одного игрока |
| `src/styles.css` | переменные темы и пурпурный фон-ключ прозрачности |

## Чего нельзя менять не подумав

**`background: #ff00ff`** у `html/body/#app` в `styles.css` — это цветовой ключ
прозрачности окна. Поменяешь — окно станет непрозрачным прямоугольником.

**Внешний край панели без скруглений.** Сглаженные пиксели границы не совпадают
с ключом точно и остаются на экране пурпурной каймой. Скругления внутри панели
безопасны: они лежат на непрозрачном фоне.

**Метрики считает C++.** Единственное исключение — CS в минуту в `PlayerRow.vue`.
Всё остальное приходит готовым: два места, где считается одно и то же число,
однажды дадут два разных ответа.
